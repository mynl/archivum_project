Archivum
========

Archivum is a local document and reference management system for academic
papers, books, reports, and technical documents. It is built around stable
identity: references are keyed by BibTeX tag, documents are keyed by content
hash, and the relationship between references and physical files is stored
explicitly.

The web application is the main day-to-day interface. It provides fast metadata
search, full-text ripgrep search, co-author and semantic network exploration,
BibTeX-aware ingest, report generation, and export workflows for CSV, BibTeX,
and BibTeX+.
