{% if publishing %}

A preprint here is a reference with an arXiv identifier and no journal. arXiv is asked first, 100 identifiers a request and one request in three seconds whatever the pace chosen, for the DOI its authors gave for the published version. Crossref is then asked for the record of each such DOI, or of the reference's own DOI, which is where the journal, volume, number and pages come from; how many is not known until arXiv has answered, hence the range. Only arXiv identifiers and DOIs are sent, and both sources are free. Results go to doi-audit/ in the library folder; the references are not changed until you accept a proposal.

{% elif searching %}

Crossref is searched first, one reference a request, and is free. OpenAlex is then searched for each reference Crossref has nothing close for; how many is not known until Crossref has answered, hence the range. For each reference its title, its first author's surname and its year are sent, and nothing else. An OpenAlex search costs 10 of the 10,000 credits a free key allows each day: {{ '{:,}'.format(p.openalex_searches[0] * 10) }} to {{ '{:,}'.format(p.openalex_searches[1] * 10) }} credits here. The run stops by itself when the day's credits run low; start it again the next day and it carries on. {% if not plan.has_key %}No OPENALEX_API_KEY is set in this server's environment, so the daily allowance is a tenth of that.{% endif %} Results go to doi-audit/ in the library folder; the references are not changed until you commit a proposal.

{% else %} {% if checking %}

OpenAlex is asked first, 100 DOIs a request; that also collects the citation counts. Crossref is then asked, one DOI a request, about each DOI OpenAlex does not confirm, and doi.org about each DOI neither has. How many go on is not known until OpenAlex has answered, hence the range.
